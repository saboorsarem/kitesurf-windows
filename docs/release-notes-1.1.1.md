# Kitesurf Browser 1.1.1 for Windows

Documentation and branding release.

- The application icon is now the official Kitesurf logo from the upstream repository, embedded at
  seven Windows sizes (16–256 px) and used in the window chrome, the welcome screen and the taskbar.
  The mark remains a Cloudflare trademark; see `NOTICE`.
- Screenshots in the README were regenerated against this build.

No behavioural changes: connection handling, screencast pacing, input mapping and the Cloudflare
Access service-token support are identical to 1.1.0. `--selftest` still passes its full suite.

Download `KitesurfBrowser.exe` below; it is self-contained (Windows 10 1809+ / 11, x64).
